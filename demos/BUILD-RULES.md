# Правила сборки демо · 14.11.2026

Демо показывает заказчику на бирже: «вот так я сделаю вам». Рамка — `docs/packaging/STANDARD.md` (ветка `packaging/standard`) и решения Саши 13.11.

## Содержание
- Каждая страница: плашка вверху или внизу «Демо-концепт · данные вымышлены» (заметная, не прячется). Названия, имена, телефоны, адреса, цены — вымышленные. Телефоны только вида `+7 (900) 000-00-00`. Реальных брендов, людей, врачей, отзывов настоящих людей нет.
- Тексты — настоящие, живые, конкретные, по-русски; никаких lorem ipsum, «текст здесь», пустых рамок, заглушек-серых прямоугольников.
- Нигде нет слов про ИИ, нейросети, названий моделей, «сделано с ИИ» (решение Саши 13.11).
- Кнопки и формы работают на странице: форма показывает «Демо: заявка никуда не уходит, в рабочей версии придёт вам на почту и в Telegram», проверка полей настоящая. Ссылки tel:/tg:/wa.me — на вымышленные номера.
- Карты: схема из SVG, без встроенных чужих карт.

## Картинки
Фото — только бесплатные по лицензии Unsplash или Pexels, настоящие и по теме (не заглушки). Файлы в `demos/<имя>/img/`, каждый ≤ 200 КБ (webp/jpg), рядом `SOURCES.md`: файл → страница фото, автор, лицензия. У `<img>` — честный `alt`, `width`/`height`, `loading="lazy"` (кроме первого экрана). Остальное — свои SVG, CSS-паттерны, градиенты, пиктограммы. Шрифты — Google Fonts (лицензия OFL) через `<link>` с запасными системными, либо системные. Иллюстрации должны выглядеть как дизайн, а не как рамки с крестиком: настоящая композиция, цвет, глубина.

## Технически
- Один файл `index.html` на вариант (CSS и JS внутри), статичный, без сборки и серверов.
- Адаптив 375 и 1280 без горизонтальной прокрутки (`overflowX:false` в отчёте снимка). Промежуточные 768–1024 тоже не ломаются.
- Тап-цели ≥ 44 px, текст ≥ 16 px на телефоне, контраст AA, `lang="ru"`, `<title>`, `<meta name="viewport">`, видимый фокус, `prefers-reduced-motion`.
- Анимации сдержанные; без них страница читается.

## Снимки
`node demos/tools/shot.mjs <файл.html> <out.png> 1280 800` и `... 375 800` — полная страница. Для первого экрана добавь `--full=0`. Скрипт печатает высоту страницы и `overflowX`. Снимки открывай Read-ом и смотри глазами; правь, пока не станет красиво.

## Эталоны
Для ниши — 5 лучших сайтов (по реальному качеству дизайна, не по рекламе). Снимки через тот же скрипт (1280 и 375) в `refs/` (png в git не идёт, `.gitignore`). В `refs/refs.md`: URL, дата, что именно в нём сильное. Не копировать код, тексты и картинки — учиться принципам: сетка, типографика, ритм, цвет, первый экран.

## Оценка
Арт-директор-скептик (Haiku) сравнивает варианты с эталонами и ставит каждому 1–10. Берём только ≥ 8 и «не хуже эталонов». Не хватило — переделка.
